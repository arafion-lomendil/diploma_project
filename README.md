## О проекте

**Контекст.** Яндекс Афиша — сервис для поиска информации о мероприятиях
и покупки билетов. Платформа работает с партнёрами: организаторами мероприятий и билетными операторами. 
Для анализа использованы данные за 2024 год, доступные на момент ноября 2024 года.

В преддверии зимних праздников сотрудники отдела продукта заметили,
что продажи билетов на одни мероприятия неожиданно растут, а на другие —
снижаются. Причины могут быть разными: сезонность, смена предпочтений
аудитории, маркетинговые кампании.

**Цель.** Провести детальный исследовательский анализ данных, выявить
инсайты об изменении пользовательских предпочтений, а также подготовить
аналитическую базу для принятия решений по новогодним акциям
и распродажам.

**Бизнес-вопросы:**
1. Какие категории событий набирают популярность, а какие теряют?
2. Как меняются ключевые метрики (выручка, заказы, средний чек)
   в динамике по сезонам?
3. Кто в лидерах среди регионов, площадок и билетных операторов?
4. Отличается ли поведение пользователей мобильных и стационарных
   устройств?

## Данные

Схема `afisha` состоит из следующих таблиц:

| Таблица     | Описание                               | Ключевые поля                               |
|-------------|----------------------------------------|---------------------------------------------|
| `purchases` | Информация о заказах билетов           | order_id, user_id, event_id, revenue, total |
| `events`    | Данные о мероприятиях на платформе     | event_id, event_type_main                   |
| `venues`    | Сведения о площадках проведения        | venue_id, venue_name, address               |
| `regions`   | Список регионов                        | region_id, region_name                      |
| `city`      | Список городов, относящихся к регионам | city_id, city_name, region_id               |

**Связи:** `purchases → events → venues → city → regions`

### Датасеты для Python-анализа

Период: **01.06.2024 – 31.10.2024**

| Файл                          | Что внутри                                                | Поле для объединения |
|-------------------------------|-----------------------------------------------------------|----------------------|
| `final_tickets_orders_df.csv` | Все заказы билетов (mobile + desktop) + `days_since_prev` | `event_id`           |
| `final_tickets_events_df.csv` | События + город, регион, площадка                         | `event_id`           |
| `final_tickets_tenge_df.csv`  | Курс KZT/RUB за 2024 год (за 100 тенге)                   | `data`               |

Дополнительный датасет с курсом валют используется для приведения
всей выручки к единой валюте — российскому рублю.

### 3. Дашборд в DataLens

Создан интерактивный дашборд, который позволяет:

- исследовать структуру выручки в разрезе категорий событий
  и типов устройств.

Дашборд включает:
- значения-индикаторы основных показателей;
- линейные графики динамики выручки, количества заказов
  и средней выручки с заказа;
- таблицы с выделением топ-сегментов по суммарной выручке;
- фильтрацию данных для удобной навигации.

**Артефакты:** [Ссылка на дашборд](https://datalens.ru/gsbq2wfy6eos0-yandeks-afisha?_share_link=org), `dashboard.md`

### 4. EDA и проверка гипотез (Python)

Проведён исследовательский анализ данных:
- предобработка и объединение датасетов;

- анализ динамики показателей в летний и осенний периоды;

## Ключевые результаты

- **Сезонность.** Осенью количество заказов заметно растёт
  во всех сегментах, особенно среди мобильных пользователей.
  Наиболее востребованы категории `концерты`, `театр`, `спорт`.
- **Средний чек.** Рост числа заказов сопровождается снижением
  средней стоимости билета (−5,32% в среднем). Наиболее сильное
  падение — у `театра` (−17,84%) и `ёлок` (−14,76%).
  Рост показали `выставки` (+6,49%) и `стендап` (+5,13%).
- **Недельная цикличность.** Пик активности приходится на пятницу,
  минимум — на воскресенье. Динамика суммарной выручки в целом совпадает с динамикой DAU.
- **Регионы.** Наибольшая доля событий приходится на Каменевский регион (26,7%) и Североярскую область (17%). По доле заказов лидируют те же регионы — 31,6% и 15,3% соответственно.
- **Партнёры-лидеры.** `Билеты без проблем` (16,7% выручки),
  `Мой билет` (12,7%), `Облачко` (12,6%). Доля заказов не всегда совпадает с долей выручки, что может быть связано с различиями в стоимости билетов и структуре продаж у партнёров.
- **Гипотезы.** Статистический тест выявил статистически значимое различие
  в среднем числе заказов на пользователя между мобильными и стационарными
  устройствами (p-value ≈ 7,25e-63). Гипотеза о более высоком среднем
  времени между заказами у мобильных пользователей **не подтвердилась**
  (t-тест и тест Манна–Уитни).
